PayWarden 1.0.0-rc.2 — initial public source release.

Self-hosted TRON USDT payment processing with signed webhooks, durable recovery,
optional sweeping, checkout and administration interfaces.

This is a release candidate. Build the runtime and migration images from the
same source tag; see `docs/deployment.md`. No prebuilt container images or private
operator artifacts are attached to this source release.

The source includes automated unit and PostgreSQL/Redis integration tests.
Configure and validate your own deployment before accepting production traffic.
